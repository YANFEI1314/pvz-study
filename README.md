# 植物学习大战 - 双子女打卡工作台 🌻

基于植物大战僵尸初代原版绿色草坪 UI 设计的双子女学习打卡应用。

## ✨ 核心特性

### 👨‍👩‍👧‍👦 双子女独立账号
- **小绿（二年级）** 和 **小葵（初二）** 两个孩子独立账号
- 侧边栏一键切换，数据完全隔离
- 家长可分别布置任务、配置心愿清单

### 📋 今日任务
- 三大任务分组：**好好学习 / 生活好习惯 / 我爱运动**
- 每条任务显示：图标、阳光奖励、截止时间
- 状态徽章：待完成、待审核、已完成、已逾期
- **拍照任务**：开启后强制唤起摄像头拍照/录像才能提交

### 🌻 我的花园
- 5×2 共 10 格种植位
- 点击植物：留在花园 / 出售兑换金币
- 连续 3 天全勤解锁 **玉米加农炮** 稀有植物

### 🛒 植物商店
四个梯度：
- 低级（向日葵、豌豆射手）：50 阳光 / 卖 15 金币
- 中级（寒冰射手、坚果、双子向日葵）：100 阳光 / 卖 35 金币
- 高级（双重射手、高坚果）：175 阳光 / 卖 60 金币
- 稀有（玉米加农炮）：325 阳光 / 卖 110 金币

### 🎁 心愿兑换中心
- 家长自定义心愿清单（如 30 分钟电视、冰淇淋、超市选购）
- 孩子消耗金币兑换 → 推送家长审核 → 通过生效

### 👨‍👩‍👧 家长端（紫色面板）
- **任务管理**：新建/编辑/删除任务，配置拍照要求
- **打卡审核**：查看照片视频，通过/驳回
- **进度查看**：实时看板（阳光/金币/花园/连勤/解锁植物）
- **心愿管理**：新增/编辑/删除心愿奖励
- **兑换审核**：审核孩子的兑换请求
- **补发/恢复**：手动补发阳光、恢复被僵尸损毁的植物

### 🧟 僵尸惩罚机制
- 单项任务超时：刷新**普通僵尸**，随机吃 1 株植物 或 扣 40 阳光
- 当日全部未完成：刷新**铁桶僵尸**，吞噬 2 株植物
- 每日 0 点自动结算

### 🌱 植物解锁规则
- 数学任务（30 阳光）→ 解锁攻击植物（豌豆射手、寒冰射手、双重射手）
- 语文任务（25 阳光）→ 解锁防御植物（坚果、高坚果）
- 英语任务（20 阳光）→ 解锁产阳光植物（向日葵、双子向日葵）
- 运动/家务任务（8-15 阳光）→ 不解锁科目植物

## 🚀 运行

```bash
pnpm install
pnpm dev        # 开发服务器
pnpm build      # 生产构建
pnpm preview    # 预览构建结果
```

默认端口：5173

## 📁 项目结构

```
src/
├── App.tsx          # 主应用入口，整合所有页面与状态管理
├── main.tsx         # React 渲染入口
├── types.ts         # TypeScript 类型定义
├── data.ts          # 植物图鉴、科目配置、规则
├── store.ts         # localStorage 持久化 + 每日刷新与僵尸惩罚逻辑
├── icons.tsx        # 内联 SVG 植物/僵尸/资源图标（24+ 种）
├── styles.css       # PVZ 绿色草坪主题样式（800+ 行）
├── Sidebar.tsx      # 左侧导航栏组件
├── TasksPage.tsx    # 今日任务页面（含拍照弹窗）
├── GardenPage.tsx   # 我的花园页面
├── ShopPage.tsx     # 植物商店页面
├── WishPage.tsx     # 心愿兑换页面
├── ParentPage.tsx   # 家长端 6 个 tab
└── components.tsx   # 通用组件（Modal/Toast/Switch/Confirm）
```

## 🎨 设计特色

- **零 emoji 依赖**：所有植物、僵尸、图标均为内联 SVG（颜色、形状完全可控）
- **PVZ 原版绿色草坪**：条带背景、向日葵资源区、圆角卡片、阳光金色
- **跨设备兼容**：CSS Grid + Flexbox 布局，适配各种分辨率
- **纯前端存储**：localStorage 持久化，无需后端
- **响应式交互**：植物摇摆动画、僵尸抖动、阳光光晕

数据存储 key：`pvz-study-state-v1`，清除浏览器 localStorage 即可重置初始数据。
